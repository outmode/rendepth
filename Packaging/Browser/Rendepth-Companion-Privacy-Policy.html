Rendepth Companion

Privacy Policy

Effective date: September 30, 2026

Publisher: Outmode · rendepth.com

This policy describes how Outmode's Rendepth Companion browser extension handles information when you use it with the Rendepth desktop application. It covers the Companion extension and its browser-to-desktop media connection, not other Rendepth products or the websites whose media you choose to open.

Media you choose to open

Rendepth Companion accesses a web image or video when you choose an “Open in Rendepth” command or use the extension's toolbar to open a playing video. If you explicitly enable automatic reconnection for a website, an active video session may reconnect after you navigate to another page on that same website. The extension uses that media only to display or convert it in the Rendepth desktop application. It does not build a browsing history or access media in unrelated tabs.

For an image, the extension reads the selected image from its page or requests it from the website hosting it, then passes the image to the locally installed Rendepth application. A request to the image's website may include the browser credentials normally used for that site. The extension does not read or save your passwords or cookies.

For a video, the extension captures the selected video and sends it to the Rendepth application through a direct local WebRTC connection. Video playback and audio stay in your browser; the extension does not send an audio track. The extension uses Chrome's native messaging interface to communicate with the installed Rendepth application and set up this connection. It does not send selected images or video to an Outmode server.

Settings and local files

The extension stores your source-quality setting and the website origins for which you explicitly enable automatic video reconnection in Chrome's local extension storage. Temporary connection status is kept in Chrome's session storage. You can turn off automatic reconnection for a site in the extension, and you can remove extension storage by uninstalling the extension or clearing its data in Chrome.

To display a web photo, Rendepth creates temporary media files on your computer. These files are normally removed when the desktop application closes. If it exits unexpectedly, temporary files may remain until Rendepth removes older runtime files on a later launch. Rendepth Companion does not upload these files to Outmode.

Sharing and other uses

Outmode does not receive or store the media you open with Rendepth Companion on its servers. The extension does not use this media or your settings for advertising, profiling, analytics, sale to data brokers, creditworthiness decisions, or lending. It does not transfer your media to third parties for those purposes. A website that hosts a selected image receives the request needed to retrieve that image and handles that request under its own privacy policy.

Rendepth Companion's use of information obtained through Chrome APIs complies with the Chrome Web Store User Data Policy, including its Limited Use requirements. The extension uses that information only to provide its stated purpose of opening selected web media in Rendepth.

Changes to this policy

If the extension's data practices change, Outmode will update this policy and the Chrome Web Store disclosure before applying the new practices.
